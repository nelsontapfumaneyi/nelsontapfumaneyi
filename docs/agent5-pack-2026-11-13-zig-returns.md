## 2. Power BI

### Data model
Get Data from **Text/CSV** for the `results/` files, and from **PostgreSQL** (login role granted `bi_reader`) for `mart.v_fx_daily`. Steps in Power Query:
- `returns_monthly`: add `period_date = Date.FromText([period] & "-01")`.
- `findings`: Add Index Column (from 0) as `row_id`. It must match the CSV row order used by the browser dashboard.
- `rolling`: change `window_days` to a whole number; nulls stay null (drawdown rows).

| Table | Type | Key | Relationships (one-to-many, single direction) |
|---|---|---|---|
| Date | dim | Date | Created with `CALENDAR(DATE(2024,4,1), DATE(2026,12,31))`; mark as date table. Joins `fx_daily[date_key]` and `returns_monthly[period_date]` |
| Instrument | dim | instrument | DATATABLE (below). Joins `returns_monthly`, `subperiods` and `rolling` on `instrument` |
| fx_daily | fact | date_key | Date |
| returns_monthly | fact | (instrument, period) | Date, Instrument |
| subperiods | fact | (subperiod, instrument) | Instrument |
| rolling | fact | (instrument, window_days, regime) | Instrument |
| scenarios | fact | scenario | none (filtered by text in measures) |
| findings | fact | row_id | none |
| Return basis | disconnected | basis | Slicer only |

```dax
Instrument = DATATABLE ( "instrument", STRING, "label", STRING, "currency_held", STRING, "sort", INTEGER, {
    { "ZWG_cash", "ZiG cash", "ZWG", 1 }, { "ZWG_savings_min", "ZiG savings (min)", "ZWG", 2 },
    { "ZWG_savings_max", "ZiG savings (max)", "ZWG", 3 }, { "ZWG_3m_deposit_min", "ZiG 3-month deposit (min)", "ZWG", 4 },
    { "ZWG_3m_deposit_max", "ZiG 3-month deposit (max)", "ZWG", 5 }, { "ZWG_ZiGDTDF_90d", "RBZ ZiGDTDF 90-day bill", "ZWG", 6 },
    { "USD_cash", "USD cash", "USD", 7 }, { "USD_tbill_3m", "US 3-month T-bill", "USD", 8 } } )

Return basis = DATATABLE ( "basis", STRING, "order", INTEGER, {
    { "USD-adjusted", 1 }, { "USD-adjusted real", 2 }, { "ZiG nominal", 3 }, { "ZiG real", 4 } } )
```

### Measures (`_Measures` table; executed in Power BI Desktop, see tie-out)
```dax
-- Display folder: Headline (values come from result_findings.csv; row_id = CSV row number)
KPI Finding = SUM ( findings[number] )                       -- use with a visual-level filter on row_id
ZiG Cash USD Return Since Launch % = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 0 )
3M Deposit Max USD Return Since 2025 % = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 4 )
3M Deposit Max Spread 2026 pp = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 6 )
Savings Max Spread 2026 pp = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 8 )
Required Yield Already ZiG % = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 12 )
Required Yield Converter 12m % = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 13 )
ZiG Cash 90d Loss Share Since 2025 % = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 17 )
3M Max 90d Loss Share Since 2025 % = CALCULATE ( SUM ( findings[number] ), findings[row_id] = 18 )

-- Display folder: Returns
Selected Basis = SELECTEDVALUE ( 'Return basis'[basis], "USD-adjusted" )
Monthly Return % =
SWITCH ( [Selected Basis],
    "USD-adjusted",      SUM ( returns_monthly[usd_adjusted_return_pct] ),
    "USD-adjusted real", SUM ( returns_monthly[usd_adjusted_real_return_pct] ),
    "ZiG nominal",       SUM ( returns_monthly[nominal_return_pct] ),
    "ZiG real",          SUM ( returns_monthly[real_zwg_return_pct] ) )
Cumulative USD Index =
VAR lastP = MAX ( returns_monthly[period_date] )
RETURN CALCULATE ( SUM ( returns_monthly[cum_usd_index] ), returns_monthly[period_date] = lastP )
Quoted Rate % p.a. = AVERAGE ( returns_monthly[rate_pct_pa] )

-- Display folder: Comparisons
Annualised USD Return % = SUM ( subperiods[annualised_pct] )
Spread vs T-bill pp = SUM ( subperiods[spread_vs_tbill_ann_pp] )
Required Yield % = SUM ( scenarios[p50] )
Required Yield (chart) % = CALCULATE ( [Required Yield %], scenarios[kind] = "required ZiG yield", scenarios[depreciation_case] = "2026 realised depreciation", KEEPFILTERS ( scenarios[hold_months] IN {3, 6, 12} ) )
Scenario P50 = CALCULATE ( SUM ( scenarios[p50] ), KEEPFILTERS ( scenarios[kind] IN {"MC relative wealth vs T-bill", "stress: 27-Sep-2024 devaluation repeats within a 12m hold"} ) )   -- P5 and P95 alike
Effective Rate 3M Deposit Max % = CALCULATE ( SUM ( scenarios[p50] ), scenarios[kind] = "effective annual rate on offer", scenarios[instrument] = "ZWG_3m_deposit_max" )   -- ZiGDTDF and savings alike
Loss Window Share % = SUM ( rolling[share_loss_pct] )
Worst Window Return % = MIN ( rolling[worst_return_pct] )

-- Display folder: FX
ZiG per USD = AVERAGE ( fx_daily[zwg_per_usd] )
ZiG per USD Month End = CALCULATE ( [ZiG per USD], LASTDATE ( 'Date'[Date] ) )
```
Format strings: `%` measures as `0.00`, with the unit in the visual title; `pp` measures as `+0.00;-0.00`.

## 3. Tableau Public story
Data source: the `results/` CSVs plus `fx_daily.csv` (a `mart.v_fx_daily` export) as an extract. All of it is public data, so it is safe for Tableau Public.

```text
// Parameter [Return Basis] (string list): USD-adjusted, USD-adjusted real, ZiG nominal, ZiG real
[Period Date]       = DATEPARSE("yyyy-MM", [period])
[Instrument Label]  = CASE [instrument] WHEN "ZWG_cash" THEN "ZiG cash" WHEN "ZWG_savings_min" THEN "ZiG savings (min)"
                      WHEN "ZWG_savings_max" THEN "ZiG savings (max)" WHEN "ZWG_3m_deposit_min" THEN "ZiG 3-month deposit (min)"
                      WHEN "ZWG_3m_deposit_max" THEN "ZiG 3-month deposit (max)" WHEN "ZWG_ZiGDTDF_90d" THEN "RBZ ZiGDTDF 90-day bill"
                      WHEN "USD_cash" THEN "USD cash" WHEN "USD_tbill_3m" THEN "US 3-month T-bill" END
[Is Focus]          = [instrument] = "ZWG_cash"      // accent colour; everything else grey
[Return (selected)] = CASE [Return Basis] WHEN "USD-adjusted" THEN [usd_adjusted_return_pct]
                      WHEN "USD-adjusted real" THEN [usd_adjusted_real_return_pct] WHEN "ZiG nominal" THEN [nominal_return_pct]
                      ELSE [real_zwg_return_pct] END
[Hold]              = TRIM(SPLIT([scenario], "|", 4))  // "hold 3 months"
[Conversion case]   = TRIM(SPLIT([scenario], "|", 2))
```

## 6. Rebuild and publish
1. Rebuild the data files: `python3 prepare_bi_data.py <results_dir> <fx_daily.csv> <data_dir>`.
2. Rebuild the Power BI project: `python3 pbip_gen.py <project_dir> "<data_dir>\\"`, open `ZiG Returns.pbip` in Power BI Desktop, Refresh > Schema and data, save. The data folder is the `DataFolder` parameter in Transform data.
3. Rebuild the Tableau sheets: `python3 twb_gen.py "<dir>\\ZiG Returns.twb" "<data_dir with forward slashes>"`; the dashboard and story are then added in Tableau (double-click sheets into a new dashboard; one story point per sheet S2 to S6).
4. Publishing to Tableau Public is Nelson's step (his account sign-in; public content). Use Server > Tableau Public > Save to Tableau Public. All data is public (RBZ, ZIMSTAT, IMF, FRED).
